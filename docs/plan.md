# Plan proposal

From docs/design.md. All owners marked proposed need team agreement; @luapreta-cloud's Rhine investigation is already underway. No implementation starts until the team agrees the stack and task boundaries. Suggested stack: Python with Streamlit for the screen, a separate Python planning engine, and independent data adapters. No database needed for the first demo.

Each task gets a fresh chat and its own branch. Status lives in its handoff file, not in this plan. Needs means the listed task outputs must be merged into main. Proposed file paths below are future outputs, not files already available.
